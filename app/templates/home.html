Allows you to search for a random GIF and preview it, before posting publicly.

  • Slash Commands: Slash command /gif and /rif will be added for searching GIF's.
  • GIF Preview: Allows you to preview your GIF before sending it to the channel.
  • Search Again: Instantly search for another GIF if you don't like the results.
    • /gif searches the Giphy Image API: www.giphy.com
    • /rif searches the Tenor Image API: www.tenor.co
